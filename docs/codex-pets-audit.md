# Codex Pets / Hide Pet 调查

调查日期：2026-10-16。用户所说的 Hide Pet 是 Codex 桌面伙伴菜单中的隐藏操作；当前客户端还使用 Pets、Mini 等名称，并非另一个必须取得源码的独立项目。

## 依据与范围

- 官方文档：[Pets](https://learn.chatgpt.com/docs/pets)、[应用设置](https://learn.chatgpt.com/docs/app/settings)、[命令参考](https://learn.chatgpt.com/docs/reference/commands)、[通知](https://learn.chatgpt.com/docs/notifications)。
- 本机已发布 Codex 的编译资源，只读检查内部版本 `26.1007.71326`、build `20398`。发行目录标识为 `26.1007.9446.0`。未修改安装文件、账户、偏好或正在使用的宠物，未调用云端服务，未复制 Codex 美术到本项目。
- DeepSeek Harness 适配基线 `0.2.0-rc.2`，提交 `04f392c9ddd144fa426da2045178797da6db6c11`。通过本机发布包确认插件接口，再独立实现功能。

客户端包含的功能不代表每个账户都已启用。语音、云端收养、部分 Mini 与对话界面具有开关和账户条件。

## 调查结果与落地

| Codex 的实际能力 | 本项目 0.2.0 的处理 |
| --- | --- |
| 显示/隐藏，启动后恢复偏好 | 持久化显示状态，`/pet show/hide` |
| 无角色的 Mini，仍有聊天与动态 | `mode: mini`，与隐藏全部操作区分 |
| 始终显示 / 按需显示，点击外部收起 | 在 Harness 应用窗口内实现 |
| 设置中选择角色与大小、重置大小 | 原生设置左栏“宠物伙伴”，大小/位置分别重置 |
| 点击打招呼、悬停跳跃、拖动与位置恢复 | 应用内实现，并增加方向键移动、Esc 还原 |
| 九种动作、v1/v2 图集、十六方向注视 | 固定图集契约；PNG/WebP 校验与预览 |
| 每帧停留时间、非待机动作三次后转慢待机 | 使用分帧时间，预览显式循环，减少动态时保持首帧 |
| 鼠标注视用于待机、工作和打招呼 | 对应状态允许 v2 注视；等待/失败/审阅不覆盖姿态 |
| 输入或审批 → waiting；完成未读 → review | 修正原先映射；错误必须来自宿主事实 |
| 多会话提醒；需要回应 > 失败 > 完成待查看 > 运行 | 订阅多个原生会话并按该优先级汇总 |
| 提醒展开/收起、关闭、按会话静音、隐藏计数 | 动态面板、单条收起、持久化静音和恢复提醒 |
| 打开具体会话、继续回复、停止运行 | 使用 Harness 的会话导航、prompt、cancel 接口 |
| 内联用户问题与真正的审批动作 | “前往处理”打开对应原生会话，由原生控件处理 |
| Quick Chat 直接发送完整文字 | 在明确工作区创建或回复原生会话；保留全文与失败反馈 |
| 文件、技能和上下文输入 | 含上下文草稿转入主输入栏，保留已有草稿，由用户发送 |
| 快捷键唤出并聚焦输入 | 保留 Harness 窗口内快捷键；Windows 桌面模式新增固定全局 Ctrl+Alt+Shift+P |
| 本地 pet.json / 旧版 avatar.json | 支持 `displayName`、`spriteVersionNumber`、`spritesheetPath` 与项目自身字段 |
| Codex 本地图集默认值 | Codex 清单默认 v1、`spritesheet.webp`；本项目清单继续支持 PNG 默认值 |
| 自定义图集更新、缓存修订与身份保持 | 校验后替换；保留 ID/元数据/偏好；内容摘要更新图片地址 |
| 刷新、创建及 v1 升级入口 | 设置页刷新；创建/升级准备原生会话草稿，配套 skill 执行 |
| 本地宠物文件夹 | CLI 可指定目录；本版未加入直接打开系统文件夹的按钮 |
| 独立透明置顶窗口、点击穿透、多显示器吸附 | Windows 0.3.2 增加独立透明置顶 WPF 窗口；透明像素穿透与多显示器吸附未实现 |
| Win+Alt+P / Option+Space 等系统全局快捷键 | Windows 使用 Ctrl+Alt+Shift+P 全局热键；占用时不阻断启动 |
| 实时双向语音、静音、字幕、语音会话 | 尚未实现；宿主输入栏语音转文字不等价于双向通话 |
| 云端宠物库、分享/收养、账号同步 | 尚未实现；本地 ZIP 导入/导出可备份迁移 |
| 紧凑对话记录、回复、附件和表情等 Mini 扩展界面 | 主会话承载完整交互；本版未在宠物旁复制完整对话视图 |

## 可核查的关键细节

图集宽 1536，格子 192 × 208，共八列；v1 高 1872，v2 高 2288。九行帧数依次为 `6,8,8,4,5,8,6,6,6`；v2 多两行，每行八个注视方向。方向从朝上开始，顺时针每 22.5° 一格。

本机 Codex 的待机时序为 `[1680,660,660,840,840,1920]` 毫秒；其他动作有独立末帧停留，默认三轮后回待机。Codex 宠物宽度范围为 80–224 像素，默认 112；本项目为保持已有偏好兼容，保留 0.35–1.5 倍缩放与默认 0.72，不宣称大小默认值完全一致。

本项目的收起提醒按观察到的会话状态转换重新激活，静音保存在当前浏览器来源。尚未实现 Codex 按每个 turn 的精确通知期限，也未连接其账号同步。这些差异与宿主交互验收范围见 [功能对齐与验证](feature-parity.md)。
