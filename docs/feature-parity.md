## 实机验收

安装插件后，在适配基线中逐项检查：

1. 宿主启动能加载插件，`pet` 命令、模型工具和宠物面板可见。
2. 轮流选择两个初始角色，重启后仍保留选择、位置和显示偏好。
3. 将宠物拖到窗口四角，缩小及放大窗口，确认边界限制和交互区域正常。
4. 验证九种状态的实际播放、左右移动，以及 v2 十六方向的顺时针语义。
5. 触发任务工作、等待用户、失败及审阅等宿主事件，确认状态转换，并记录宿主未暴露的状态。
6. 导入有效自定义宠物、拒绝无效图集、导出后在独立数据目录重新导入；验证改名、删除和失效选择的处理。
7. 开启减少动画、调整缩放、隐藏并重新显示；检查切换页面或卸载扩展时没有残留宠物。
