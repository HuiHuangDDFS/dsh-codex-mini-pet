## 已知差异

- Windows 桌面版 0.3.2 使用独立透明置顶 WPF 窗口，Harness 后台/最小化时仍可见；固定全局 Ctrl+Alt+Shift+P 可唤出快速聊天。Web/其他平台保持应用内显示。透明像素穿透、多显示器吸附未实现；负坐标存储和工作区边界限制已实现，多屏混合 DPI 尚未实机验证。
- 实时双向语音、Codex 云端宠物库、分享收养和账号同步尚未实现。主输入栏可承载宿主自己的文件和语音输入，不表示具备 Codex 实时语音。
- 审批与提问在对应原生会话处理；宠物栏不复制审批控件。紧凑对话记录、附件回复和表情等完整 Mini 对话视图尚未移植。
- 本版保留已有缩放范围与默认值。通知收起按观察到的状态转换恢复，未实现 Codex 每个 turn 的精确过期时长。
- 本地宠物目录可以经 CLI 管理，设置页暂未提供直接打开系统文件夹的按钮。
- `validate` 证明文件结构与像素布局符合契约，不证明动作连贯、角色方向或美术完成度。初始形象的来源与限制见 [资源说明](assets.md)。
