# 初始角色资源

初始角色采用 DeepSeek 鲸鱼娘 Q 版与用户先前选择的智域形象。两个初始图集都采用 v2（1536 × 2288），包含九种动画状态和十六方向行。

| 名称 | 资源目录 | 来源 |
| --- | --- | --- |
| 深蓝鲸娘 | `assets/pets/whale-girl` | 本项目新生成的蓝白鲸鱼主题 Q 版角色 |
| 智域 | `assets/pets/zhiyu` | 用户此前批准并选用的现有图集 |

鲸鱼娘按蓝白鲸鱼主题创作 Q 版形象。当前没有用户提供的准确角色图片，因此不将其标为某张流行图片的像素级复刻，也不暗示 DeepSeek 官方授权。

智域以用户引用的既有角色为身份依据；角色来源与图集生成、裁切、校验及预览信息应与最终资源一起保留。视觉身份检查和结构校验分别记录。

两张最终 PNG 均已通过插件 CLI 结构校验（`ok: true`），并检查了完整图集。鲸娘另检查了九种状态与四个正方向的静态联系表，以及暗底透明边缘。

鲸娘存在生成式画面的细微脸型、服装和手部变化；失败与等待在小尺寸下可能较接近，注视行的头身比例也与动作行稍有区别。十六方向是二维视觉近似，结构校验不证明严格的三维等角度转动。实际连续播放和宿主交互仍需实机检查。

详细来源、生成过程与最终文件摘要见 [鲸娘来源说明](../assets/pets/whale-girl/provenance.md) 和 [智域来源说明](../assets/pets/zhiyu/provenance.md)。更多验证结果见 [功能对齐说明](feature-parity.md)。代码采用仓库许可证；角色参考来源和美术资源的许可说明以各自清单为准，不把外部参考素材自动纳入代码许可。
